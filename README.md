# Onur Aytekin — personal site

Built with [al-folio](https://github.com/alshedivat/al-folio) and deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

Where to edit:

- `_pages/about.md` — bio on the home page
- `_bibliography/papers.bib` — publications (`selected = {true}` shows a paper on the home page)
- `_projects/` — one Markdown file per project
- `_news/` — short announcements
- `_data/cv.yml` and `assets/pdf/Onur_Aytekin_CV.pdf` — CV page and PDF
- `_data/socials.yml` — email, LinkedIn, GitHub links

Local preview: `bundle install && bundle exec jekyll serve`, then open http://localhost:4000/portfolio/.
